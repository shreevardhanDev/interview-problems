# Java DSA Project

This project contains 100 ordered Java solutions to common interview and LeetCode-style DSA problems. Each problem is stored in its own file under `src/main/java/com/example/dsa/` and includes the problem statement, a solved implementation, and an example `main` for quick execution.

## Run instructions
1. Install Java 25 or later.
2. Run `./gradlew run -PmainClass=com.example.dsa.Problem001_TwoSum` from the project root.
3. Replace `Problem001_TwoSum` with any numbered problem class.
